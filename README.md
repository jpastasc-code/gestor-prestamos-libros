# Gestor de préstamos de libros

Taller **Desarrollo de software dirigido por especificaciones con asistencia de IA** · Ingeniería de Software · UNAL.

Aplicación de consola en **Java** para administrar el catálogo de una biblioteca universitaria y registrar préstamos y devoluciones, desarrollada con el ciclo *Spec-Driven Development* (Iroko, 2026).

## Estructura
| Carpeta | Contenido |
|---|---|
| `docs/` | Intención, requisitos, especificaciones, trazabilidad, decisiones, convenciones |
| `tasks/` | Tareas de implementación (TASK) |
| `tests/` | Planes y casos de prueba (TEST) |
| `src/` | Código fuente |
| `review/` | Revisiones, registro de cambios e interacciones con la IA |
| `agent/` | `AGENT.md`, contexto y prompts usados con la IA |
| `ops/` | Guía de ejecución y mantenimiento |
